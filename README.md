# Портфолио Зарлык

Статический сайт на HTML, CSS и JavaScript. Без сборки, бэкенда, внешних шрифтов и платных зависимостей. WhatsApp: +7 705 550 82 05.

## Файлы

- `index.html` — тексты, проекты, контакты и метаданные.
- `styles.css` — дизайн и адаптивные версии.
- `script.js` — мобильное меню, мягкое появление секций и год в подвале.
- `assets/` — реальные снимки двух демонстрационных сайтов и favicon.
- `cloudflare-ready/` — самостоятельный комплект файлов для публикации.

Оба проекта прямо обозначены как демонстрационные концепты, а не оплаченные заказы или официальные сайты клиентов. В контактах работают кнопки WhatsApp, Instagram (https://www.instagram.com/almezulyy/) и Telegram (https://t.me/ZarlykSh). Все открываются в новой вкладке, используют встроенные SVG-иконки и адаптируются под телефон.

## Просмотр

Откройте `index.html` в браузере. Для проверки через HTTP можно запустить `python -m http.server 8000` в папке сайта и открыть `http://localhost:8000`.

## Публикация

Загрузите содержимое `cloudflare-ready` в статический проект Cloudflare Pages. `index.html` должен оказаться в корне опубликованного сайта. Сборка и переменные окружения не нужны. Файл `_headers` задаёт заголовки безопасности на хостинге.

Для подключения репозитория используйте папку вывода `cloudflare-ready` без команды сборки. Инструкции сервиса: https://developers.cloudflare.com/pages/get-started/direct-upload/

Canonical, og:url, абсолютные ссылки на социальное изображение 1200 × 630, robots.txt и sitemap.xml настроены для https://zarlyk-portfolio.pages.dev/. Title, description, Open Graph, favicon и семантическая структура подготовлены. При смене домена обновите адреса в index.html, robots.txt и sitemap.xml. При изменениях исходников обновляйте их копии в cloudflare-ready.

## Проверка

Браузерная проверка выполняется локально через `.qa/check.cjs` и установленный Microsoft Edge; инструменты проверки не входят в публикацию. Она проверяет ширины 320–1920 px, отсутствие горизонтального переполнения, изображения, меню, якоря, адреса ссылок, открытие WhatsApp и работу без JavaScript. Переход WhatsApp проверяется с перехватом страницы: сообщения не отправляются.
